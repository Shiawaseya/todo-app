# Student Planner / Todo App

A mobile and web task management application built with **Ionic Framework**, **React**, **TypeScript**, and **Capacitor**.

## Prerequisites

Before running this project, make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) (included with Node.js)
- **Ionic CLI** (optional, for Ionic-specific commands):
  ```bash
  npm install -g @ionic/cli
  ```
